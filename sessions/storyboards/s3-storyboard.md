# Comic Storyboard: Session 3 (The Lounge & The Ambush)

This storyboard documents the page-by-page panel layouts and image generation prompts for **Session 3: The Celestial Lounge and The Ambush**, styled as a detailed 2D graphic novel.

---

## 🎨 Art Style Guide

To maintain visual consistency when generating these images:

*   **Prompt Style Core:** `Detailed 2D graphic novel style, clean expressive manga-style linework, crisp black ink outlines, cel-shaded color flats, cinematic volumetric lighting, warm atmospheric twilight gradient`
*   **Negatives/Bans:** `--no 3D render, realism, hyper-detailed, muddy colors, dark grit, muted tones, spacesuit, tank treads`

---

### Page 1: Crown and Ruin (Celestial Lounge)
![Final Page - Session 3, Page 1](assets/s3_page1.png)

*Layout Design:* **Asymmetrical Grid Layout** — 1 wide top panel and 2 bottom panels (left: vertical, right: square).

#### Panel 1 (Wide Top Panel): The Dice Game
*   **Art Generation Prompt:**
    `A wide-angle panel set in the opulent, gaslamp-lit Celestial Lounge. Loami (broad blue-gray soot-covered grease monkey from reference image) rolls glowing dice across a green velvet table during a game of 'Crown and Ruin'. Valentine Sterling (a nervous student) and Ember watch. A speech bubble above Loami says: "Looks like Ruin for you, Val! Pay up." Detailed 2D graphic novel style, clean manga-style linework, cel-shaded color flats, cinematic lighting.`
