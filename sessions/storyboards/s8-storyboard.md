# Comic Storyboard: Session 8 (The Written Exam & Squad 907)

This storyboard documents the page-by-page panel layouts and image generation prompts for **Session 8: The Written Exam & Squad 907**, styled as a detailed 2D graphic novel.

---

## 🎨 Art Style Guide

*   **Prompt Style Core:** `Detailed 2D graphic novel style, clean expressive manga-style linework, crisp black ink outlines, cel-shaded color flats, cinematic volumetric lighting`
*   **Negatives/Bans:** `--no 3D render, realism, hyper-detailed, muddy colors, dark grit, muted tones, text, typography, watermarks`
